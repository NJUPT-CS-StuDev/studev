12288-12543.pbf is the empty range descriptor from the same MapLibre font
endpoint. 65280-65535.pbf is an equivalent empty descriptor for that range.
These ranges contain CJK punctuation rendered locally by MapLibre 13.7.1.
All supplied campus labels are covered by these ranges plus Android's local
ideograph rendering. No glyph server is contacted at runtime.
