# 两端首页展示规则

Android `home/HomeRecommendations.kt` 与网页 `homePolicy.ts` 使用相同测试向量。
地点、用途、分类、推荐候选、开放时间和入口全部来自同一数据包；这里仅规定展示顺序。

校园时间为中国时间。05–10 点优先教学楼、图书馆、食堂；11–13 点食堂、超市；
14–16 点教学楼、图书馆、体育；17–18 点食堂、超市；19–21 点图书馆、教学楼、体育；
其余时段宿舍、超市。首页只取 featured 且有中心点的非教室地点，每分类最多三项；
明确关闭的食堂和超市不推荐。分类页包括非 featured 和已关闭地点，不限制数量。

先按时段分类优先级，再按营业中/即将关闭、未知、已关闭排序，然后按直线距离、
地点 ID 的 Unicode 顺序排序。分类页省略分类优先级，其余相同。未定位以校区中心
为起点，并明确标识。距离使用 6371008.8 米地球半径的 Haversine 公式。

开放区间左闭右开。考虑昨日跨夜窗口、今日及次日窗口；合并相邻和重叠窗口。
剩余不超过 30 分钟为即将关闭，全天连续服务不会在午夜前误报关闭。
未知开放时间不显示状态或占位文案，保留用途。完整周表保留原始区间与备注。

路线和经由摘要直接使用 wayfind 结果，网页不自行拼接路线或改变方案排序。
