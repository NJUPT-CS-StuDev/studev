### 第一问：为什么凭空冒出了两个不同的字母 $\xi$ 和 $\eta$？

你在课本上学到的罗尔定理、拉格朗日中值定理、柯西中值定理，结论全都是“存在某个中值点 $\xi \in (a, b)$”。那为什么这道题里会有两个？

我们先回到中值定理的**物理本质**：
中值定理是一个**纯粹的“存在性定理”**。它只告诉你“有”，却绝对不告诉你“它具体在哪里”。
- 拉格朗日告诉你：你开车从南京到仙林，全程平均时速是 $60\text{ km/h}$，那么途中**至少有某一个瞬间 $\xi$**，速度表指针恰好指在 $60$。
- 柯西告诉你：如果你的朋友开着另一辆车也从南京到仙林，两辆车的位移之比，等于**某一个瞬间 $\eta$** 两车瞬时速度之比。

现在请你思考一个致命问题：
**你速度达到 $60$ 的那个瞬间 $\xi$，跟你们俩相对速度比值成立的那个瞬间 $\eta$，凭什么必须是同一秒钟？**

完全没有道理是同一秒，对不对？
数学是全天下最诚实也最讲究逻辑的学科：
1. 如果你在同一个区间 $[a, b]$ 上，对同一个函数或者不同函数**应用了两次定理**；
2. 或者你把区间拆成了两半 $[a, c]$ 和 $[c, b]$，在左边用了一次，右边用了一次；
只要是**两次独立施展中值定理**，每一次抽出的那个点，就绝不能强行保证落在同一个位置。

> **【定理破案直觉 1】**：
> 凡是在考题结论里看到**两个不同的中值字母 $\xi$ 和 $\eta$**（且没有指定大小关系），你的第一反应必须是：
> **这道题必然使用了两次独立的中值定理！**
> 它要么是对两个子区间分别用了定理，要么是**在整个区间 $[a, b]$ 上，分别用了两种不同的中值机制（比如一次拉格朗日，一次柯西）**。

因此，$\xi$ 和 $\eta$ 绝不是凭空冒出来的，它们是两次不同中值操作留下的两个独立脚印。

### 第二问：那个二次函数 $g(x)=x^2$，到底是怎么神仙下凡想出来的？

答案绝不是神仙托梦，它被白纸黑字地刻在题目的结论里。
现在拿起铅笔，看我们怎么在草稿纸上做**“变量解耦”与“逆推破案”**。

#### 第 0 步：把目标式放在审讯台上
我们要证的目标是：
$$f'(\xi) = \frac{a+b}{2\eta} f'(\eta)$$

仔细观察这个式子，左边只有 $\xi$，右边有 $a, b, \eta$。
我们像刑侦破案一样，对右边这个复合怪兽做**特征解构**：

$$\text{右边} = \underbrace{(a+b)}_{\text{线索 1}} \cdot \underbrace{\frac{1}{2\eta}}_{\text{线索 2}} \cdot \underbrace{f'(\eta)}_{\text{线索 3}}$$

#### 侦探审问线索 2：这个 $2\eta$ 是谁？
在大一的高数世界里，导数符号从不会单独出现。
$\eta$ 是一个导数点，那 $2\eta$ 是什么？
你学求导公式的时候，谁求导会出现 $2x$？
$$(x^2)' = 2x \implies (x^2)'\big|_{x=\eta} = 2\eta$$
**看！分母上的 $2\eta$，本质上就是一个二次函数在 $\eta$ 处的导数！**

#### 侦探审问线索 3：把 $f'(\eta)$ 和 $2\eta$ 拼在一起
如果把分子上的 $f'(\eta)$ 和分母上的 $2\eta$ 绑在一起，写成：
$$\frac{f'(\eta)}{2\eta} = \frac{f'(\eta)}{(x^2)'\big|_{x=\eta}}$$
请停顿三秒钟，看着这个分式：
分子是一个函数的导数 $f'(\eta)$，分母是另一个函数 $g(x) = x^2$ 的导数 $g'(\eta)$！
两个函数的导数相比 $\frac{f'(\eta)}{g'(\eta)}$，这难道不就是课本上**柯西中值定理**左边最经典的模样吗？！

#### 侦探审问线索 1：那被孤立的 $(a+b)$ 又是怎么回事？
如果真的存在辅助函数 $g(x) = x^2$，那么柯西中值定理在区间 $[a, b]$ 上的右半边会是什么？
根据柯西中值定理公式：
$$\frac{f'(\eta)}{g'(\eta)} = \frac{f(b) - f(a)}{g(b) - g(a)}$$
我们试着把 $g(x) = x^2$ 代进去算一下分母：
$$g(b) - g(a) = b^2 - a^2$$
初中平方差公式立刻在脑海中炸开：
$$b^2 - a^2 = (b - a)(b + a)$$
两边同除以 $(b - a)$：
$$\frac{b^2 - a^2}{b - a} = a + b$$
看到没有？！
**题目里的那个 $(a+b)$，根本不是什么常数系数，它正是 $(b^2 - a^2)$ 与 $(b - a)$ 约分后剩下的残影！**

### 第三幕：逆推拼图——两座孤岛的“过桥中介”

现在，我们把刚才破译的所有密码拼在草稿纸上：

1. **柯西中值定理告诉我们**：对 $f(x)$ 和 $g(x)=x^2$ 在 $[a, b]$ 上使用定理，存在 $\eta \in (a, b)$ 使得：
   $$\frac{f'(\eta)}{2\eta} = \frac{f(b) - f(a)}{b^2 - a^2}$$
   把分母展开：
   $$\frac{f'(\eta)}{2\eta} = \frac{f(b) - f(a)}{(b - a)(a + b)}$$
   把 $(a+b)$ 乘到左边去：
   $$\frac{a+b}{2\eta} f'(\eta) = \frac{f(b) - f(a)}{b - a}$$

2. 盯住右边看！右边是什么？
   $$\frac{f(b) - f(a)}{b - a}$$
   这不就是 $f(x)$ 在整个区间 $[a, b]$ 上的平均变化率吗？！
   **拉格朗日中值定理**瞬间登场：
   必存在一个点 $\xi \in (a, b)$，使得：
   $$f'(\xi) = \frac{f(b) - f(a)}{b - a}$$

3. 两式右边一模一样，都是 $\frac{f(b)-f(a)}{b-a}$ 这个“红娘”！
   红娘两头一牵，左边等于左边：
   $$f'(\xi) = \frac{a+b}{2\eta} f'(\eta)$$
   全案告破！

### 第一幕：若跨过原点，会遭遇什么致命灾难？

假设出题人手抖了一下，把条件改成了包含原点的对称区间，比如 $[-1, 1]$（即 $a = -1, b = 1$）。
此时，我们的草稿纸上依然写着令 $g(x) = x^2$。灾难在三个维度同时爆发：

#### 灾难 1：结论自身发生“分母为 0”的数学猝死
看看我们要证明的目标式：
$$f'(\xi) = \frac{a+b}{2\eta} f'(\eta)$$
注意到右边分母赫然坐着一个 $2\eta$！
在实数域内，**分母为 0 是绝对的禁忌**。如果中值点 $\eta$ 恰好落在了 $0$ 点（即 $\eta = 0$），那么 $\frac{a+b}{2\cdot 0}$ 根本就不是一个合法的数学对象，整个结论瞬间丧失意义。

#### 灾难 2：柯西公式的底座直接被抽空（$g(b) - g(a) = 0$）
我们再看柯西中值定理的形式：
$$\frac{f(b) - f(a)}{g(b) - g(a)} = \frac{f'(\eta)}{g'(\eta)}$$
当 $a = -1, b = 1$ 时：
$$g(b) - g(a) = 1^2 - (-1)^2 = 1 - 1 = 0$$
左边的分母直接变成了 $0$！你连把柯西定理的式子写在卷子上的资格都被剥夺了。

#### 灾难 3：定理核心前提彻底瓦解（$g'(x) = 0$ 在区间内发生）
柯西中值定理明文规定：**在开区间 $(a, b)$ 内，$g'(x)$ 必须处处不为 0。**
为什么课本要这么轴？
因为柯西中值定理的证明，底层是构造辅助函数 $\varphi(x) = f(x) - \lambda g(x)$ 去打罗尔定理。如果 $g'(x)$ 在区间内有零点，罗尔定理的逆推链条就会断裂。
对于 $g(x) = x^2$，它的导数是：
$$g'(x) = 2x$$
如果区间是 $(-1, 1)$，那么在 $x = 0 \in (-1, 1)$ 这个点上：
$$g'(0) = 2 \times 0 = 0$$
**定理的大门被当场焊死——你根本不能合法引用柯西中值定理！**

### 第二幕：为什么 $0 \le a < b$ 能像金钟罩一样保驾护航？

现在，我们再回过头看题目给出的『$0 \le a < b$』。
请看数学家是如何用短短四个字符，完成精密的“四重排雷”的：

#### 排雷 1：检验开区间内导数是否恒不为零
函数的导数是 $g'(x) = 2x$。
我们要考察的是它在**开区间** $(a, b)$ 内部的表现。
因为已知：
$$0 \le a < x < b$$
请盯住这个不等式链：
$$x > a \ge 0 \implies x > 0$$
看到了吗？**开区间内的任何一个点 $x$，都严格大于 $a$，而 $a \ge 0$，因此 $x$ 必然严格大于 $0$！**
既然 $x > 0$，那么：
$$g'(x) = 2x > 0 \neq 0, \quad \forall x \in (a, b)$$
**排雷成功！在整个开区间 $(a, b)$ 内，导函数 $g'(x)$ 恒正，绝不可能等于 0！**

#### 排雷 2：检验端点函数值差是否不为零
根据平方差公式：
$$g(b) - g(a) = b^2 - a^2 = (b - a)(b + a)$$
因为 $a < b$，所以 $b - a > 0$；
又因为 $0 \le a < b$，两个非负数相加，且其中 $b > 0$，因此：
$$b + a > 0$$
两个正数相乘：
$$g(b) - g(a) = (b - a)(b + a) > 0 \neq 0$$
**排雷成功！分母绝对不为零！**

#### 排雷 3：中值点 $\eta$ 的安全落地
由于柯西中值定理给出的点 $\eta$ 必须在开区间内：
$$\eta \in (a, b) \implies 0 \le a < \eta < b \implies \eta > 0$$
所以最终结论中的分母：
$$2\eta > 0 \neq 0$$
百分之百安全，没有任何除以零的系统风险！

> **【证明片段示范】**：

> 显然，$g(x)$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导，且其导数为 $g'(x) = 2x$。
> 
> $\because 0 \le a < b$，
> $\therefore \forall x \in (a, b)$，均有 $x > a \ge 0$，即 $x > 0$。

> 
> 满足柯西中值定理全部条件。故由柯西中值定理可知，必存在 $\eta \in (a, b)$，使得：
> $$\frac{f(b) - f(a)}{b^2 - a^2} = \frac{f'(\eta)}{g'(\eta)} = \frac{f'(\eta)}{2\eta}$$

### 第一部分：【满分卷面示范】（100% 阅卷标准·零扣分规范）

在期末考试或考研考场上，阅卷老师看一份证明题只需要 15 秒。按照以下结构书写，字字踩在采分点上：

***

**证明**：

**第一步：应用拉格朗日中值定理**
$\because$ 函数 $f(x)$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导，
由拉格朗日中值定理可知，在开区间 $(a, b)$ 内至少存在一点 $\xi \in (a, b)$，使得：
$$f'(\xi) = \frac{f(b) - f(a)}{b - a} \quad \text{——（式 ①）}$$

**第二步：构造辅助函数并严格检验柯西中值定理条件**
构造辅助函数 $g(x) = x^2$。
显然，$g(x)$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导，且其导函数为 $g'(x) = 2x$。

$\because 0 \le a < b$，
$\therefore \forall x \in (a, b)$，恒有 $x > a \ge 0$，即 $x > 0$。
从而导函数满足：
$$g'(x) = 2x \neq 0, \quad \forall x \in (a, b)$$
且端点差满足：
$$g(b) - g(a) = b^2 - a^2 = (b - a)(b + a) \neq 0$$

**第三步：应用柯西中值定理**
函数 $f(x)$ 与 $g(x)$ 在区间 $[a, b]$ 上完全满足柯西中值定理的前提条件。
由柯西中值定理可知，在开区间 $(a, b)$ 内至少存在一点 $\eta \in (a, b)$，使得：
$$\frac{f(b) - f(a)}{g(b) - g(a)} = \frac{f'(\eta)}{g'(\eta)}$$
将 $g(x) = x^2$ 及其导数代入，得：
$$\frac{f(b) - f(a)}{b^2 - a^2} = \frac{f'(\eta)}{2\eta}$$

**第四步：代数化简与中介联立**
将上式分母展开为平方差：
$$\frac{f(b) - f(a)}{(b - a)(a + b)} = \frac{f'(\eta)}{2\eta}$$
$\because 0 \le a < b \implies a + b > 0 \neq 0$，两边同乘以 $(a + b)$，得：
$$\frac{f(b) - f(a)}{b - a} = \frac{a + b}{2\eta} f'(\eta) \quad \text{——（式 ②）}$$

将式 ① 代入式 ② 的左端，即得：
$$f'(\xi) = \frac{a + b}{2\eta} f'(\eta)$$
其中 $\xi, \eta \in (a, b)$。

**证毕。**

### 第二部分：【思维模型固化】（双中值 $\xi, \eta$ 破局元认知系统）

以后在卷子上只要看到结论同时出现两个中值字母 $\xi$ 和 $\eta$，立刻调出下面这套**“双轨决策图谱”**：

#### 1. 战略分流法则：区间拆分 vs 定理联立
- **类型 A：区间拆分型（分段击破）**
  - **题眼特征**：结论中出现了 $\xi < \eta$ 的明确大小次序；或者结论是两个导数的加权求和（如 $f'(\xi) + f'(\eta) = \dots$）；或者出现了区间中点 $\frac{a+b}{2}$。
  - **核心操作**：在区间内部找一个分水岭 $c \in (a, b)$（通常是中点 $\frac{a+b}{2}$），将大区间切成 $[a, c]$ 和 $[c, b]$，在两个子区间上分别用同一定理。
- **类型 B：定理联立型（同域多模·红娘过桥法）——即本题模型**
  - **题眼特征**：$\xi, \eta$ **没有大小顺序约束**，都在全区间 $(a, b)$ 内；结论通常是**乘积、商或比例关系**（如 $f'(\xi) = K(\eta) f'(\eta)$）。
  - **核心操作**：在同一个区间 $[a, b]$ 上同时施展两次中值操作（通常是一次拉格朗日，一次柯西），寻找它们的**公共中介量**（最经典的就是平均变化率 $\frac{f(b)-f(a)}{b-a}$），令红娘牵线直接消去！

#### 2. 战术逆推法则：辅助函数 $g(x)$ 的“五大基因图谱”
柯西中值定理的辅助函数 $g(x)$ 从来不靠猜，它在式子里留下的“导数痕迹”和“端点差痕迹”是互为镜像的：

| 题目中露出的导数痕迹 $g'(\eta)$ | 题目中露出的端点痕迹 $g(b)-g(a)$ | 锁定的辅助函数 $g(x)$ |
| :--- | :--- | :--- |
| **$2\eta$** | **$b+a$**（由 $\frac{b^2-a^2}{b-a}$ 约分而来） | **$g(x) = x^2$**（本题） |
| **$3\eta^2$** | **$b^2 + ab + a^2$**（由 $\frac{b^3-a^3}{b-a}$ 约分而来） | **$g(x) = x^3$** |
| **$-\frac{1}{\eta^2}$** 或 **$\eta^2$ 出现在分子** | **$\frac{1}{ab}$**（由 $\frac{1/b - 1/a}{b-a}$ 通分而来） | **$g(x) = \frac{1}{x}$** |
| **$\frac{1}{\eta}$** | **$\ln b - \ln a$** 或 $\ln \frac{b}{a}$ | **$g(x) = \ln x$** |
| **$e^\eta$** | **$e^b - e^a$** | **$g(x) = e^x$** |

**一句话心法**：**导数项看形态，端点项看变形；二者对齐之日，就是辅助函数原形毕露之时！**
