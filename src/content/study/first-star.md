写代码并不只是独自对着编辑器。你会读别人的项目，记录自己的想法，也会和人一起修改同一份作品。先用 StuDev 这个网站，试一次。

不必按难度给自己贴标签。下面三关可以只做第一关，也可以继续往前走。**Star 是收藏，不是作业。**

## 01 · 找到它

打开 [StuDev 的 GitHub 仓库](https://github.com/NJUPT-CS-StuDev/studev)。GitHub 是存放和协作修改代码的平台；这个网站的源文件也在那里。

1. 如果还没有账号，按 GitHub 的页面提示注册一个。记住用户名，不要在公开讨论里留下手机号、学号或密码。
2. 在仓库里找到 `src/pages/index.astro`。打开文件，对照 [StuDev 首页](/)，看看哪一行写出了首页的名字。
3. 记下一件你看懂的事，或者一个你没看懂的问题。

做到这里就已完成第一关。想收藏这个项目，可以点仓库右上角的 Star；不点也完全不影响后面的挑战。

## 02 · 留下自己的第一次修改

在 GitHub 上新建一个**自己的**公开或私有仓库，取一个简单的名字，例如 `my-first-repo`。创建时勾选添加 README，然后在网页里编辑它，写下两句：

```text
今天我第一次打开了一个项目的源文件。
我想用这个仓库记录……
```

点击页面上的提交按钮。你刚刚完成了一次 commit：为文件的变化留下一个可回看的记录。这一关不需要安装 Git，也不需要复制别人的代码。

## 03 · 让作品变得更好

回到 StuDev，看看这篇文章或网站有没有一处可以改进：一句不清楚的说明、一个手机上不方便点的地方，或者一个值得写的选题。

到仓库的 [Discussions](https://github.com/NJUPT-CS-StuDev/studev/discussions) 说清楚“我看到什么、希望怎样”；如果是明确的错误，也可以开一个 [Issue](https://github.com/NJUPT-CS-StuDev/studev/issues)。不用为了过关硬找问题，更不用提交空白 PR。

如果你已经会改代码，欢迎直接提出 Pull Request。我们会一起看改动，而不是按技术熟练度给人排队。

## 第一次例会

愿意的话，带来你在任一关的发现：一个问题、一段 README，或者一次修改。现场会留时间互相展示和交流；那颗实物小星星，也会从愿意分享过程的同学中抽出一位送出。**不以 Star、PR 数量或关卡等级作为抽取条件。**
