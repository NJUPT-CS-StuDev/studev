从 StuDev 仓库开始。你会找到首页的源文件，在自己的仓库提交一次修改，再给 StuDev 留下建议。

## 01 · 打开源码

打开 [StuDev 的 GitHub 仓库](https://github.com/NJUPT-CS-StuDev/studev)。GitHub 可以存放代码，也可以协作修改。

1. 注册 GitHub 账号，记下你的用户名。
2. 在仓库里找到 `src/pages/index.astro`。打开文件，对照 [StuDev 首页](/)，看看哪一行写出了首页的名字。
3. 点击仓库右上角的 Star，记下一件你看懂的事，或者一个想问的问题。

## 02 · 留下自己的第一次修改

在 GitHub 上新建一个仓库，例如 `my-first-repo`。创建时勾选添加 README，然后在网页里写下你想学的一件事。

点击页面上的提交按钮。你刚刚完成了一次 commit，为这次修改留下了记录。

## 03 · 让作品变得更好

回到 StuDev，找一处可以改进的地方：一句读不顺的说明、一个手机上不方便点的地方，或者一个值得写的选题。

到仓库的 [Discussions](https://github.com/NJUPT-CS-StuDev/studev/discussions) 写下“我看到什么、希望怎样”。发现明确的错误，也可以提交 [Issue](https://github.com/NJUPT-CS-StuDev/studev/issues)。

会修改代码的同学，可以直接发起 Pull Request。

## 第一次例会

带上你的发现或作品：一个问题、一段 README，或者一次修改。我们会在现场展示、交流，并从完成任一关的同学中抽出一位，送出那颗实物小星星。
